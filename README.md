# Keyflash
Keyflash is a lightweight Windows utility that makes keyboard backlighting react to keystrokes with fast, customizable flash effects.

# Features
- Reactive keyboard backlight flashing
- Adjustable flash duration
- Ignores repeated signals while a key is held
- Startup & Silent launch support
- Lightweight and simple to use

# Designed for supported Lenovo LOQ keyboard backlighting

# Usage
Run Keyflash, enable the flash effect, and adjust the flash duration to your preference.
Keyflash is currently built around the keyboard backlight behavior available on supported Lenovo LOQ devices.
